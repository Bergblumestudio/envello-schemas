# Security Policy

## Supported Versions

`@envello/schemas` is pre-1.0 and still in active early development. Only the latest published version on npm receives security fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
| < 0.1   | ❌        |

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities. Instead, email **hello@aktai.app** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce, or a proof-of-concept if you have one
- The affected version(s)

We'll acknowledge your report within 3 business days and aim to provide a fix or mitigation timeline within 14 days for confirmed issues. We'll credit you in the release notes unless you'd prefer to stay anonymous.

This package is a mirror of `packages/schemas` in the private Envello monorepo, which is the actual source of truth. Vulnerabilities here likely apply to the monorepo copy too — please mention that in your report.
